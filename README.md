# Gaiensai-ticket

外苑祭のQRコードによる受付システムです。来場者はQRコードを提示し、スタッフがそれをスキャンすることでスムーズな受付を実現します。仕様について詳しくは`manuscript.md`に記載があります。

## 機能 (Features)

* **QRコード発行機能:** 生徒により事前に来場者向けのQRコードを発行。
* **QRコード受付:** スマートフォンやカメラでQRコードを読み取り、来場者の受付処理を実行。
* **読み取り履歴・受付状況の確認:** 管理画面で現在の受付人数や読み取り履歴を確認可能。

## 技術スタック (Tech Stack)

このプロジェクトで使用されている主な技術です。

* **フロントエンド:** HTML, CSS, JavaScript
* **バックエンド:** なし
* **データベース:** なし(今後実装予定)
* **その他:** jQuery、html5-qrcode.js, qrcode.jsなどのライブラリ

## セットアップ (Getting Started)

このプロジェクトをローカル環境で動かすための手順です。(未実装)

### 1. リポジトリをクローン

```bash
git clone https://github.com/[your-username]/gaiensai-ticket.git
cd gaiensai-ticket
```

### 2. アプリケーションの起動

そのままWebサーバーにアップロードして利用できます。
ローカルでテストする場合は、以下のコマンドでサーバーを立ち上げることも可能です。

```bash
# 例: Node.jsを利用する場合
npx http-server
```

ブラウザで `http://localhost:8080` にアクセスしてください。

## 使い方 (Usage)

1. 受付担当者は、読み取りページにアクセスをします。
2. [スキャン開始] ボタンをクリックし、カメラを起動します。
3. 来場者が提示するQRコードをカメラで読み取ります。
4. 受付結果（成功、失敗、再入場など）が画面に表示されます。
